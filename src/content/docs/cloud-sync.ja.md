**デバイス間で同期** をオンにすると、サインインしたどのデバイスでも、キャンバス、学習、設定がそろいます。スイッチはアカウント全体に一つだけで、キャンバスごとではありません。あなたがオンにするまではオフのままです。

## 同期をオンにする

1. アカウントでサインインします（ゲストセッションでは使えません）。Cloud プランが必要です。
2. **設定 → データと同期** を開き、**デバイス間で同期** をオンにします。

すぐにアカウント全体に適用され、サインインしたデバイスはどれも自動で同期します。オンにしたとき、サーバーはその日時と、そのとき表示されていたプライバシーポリシー（英語）のバージョンを記録します。Cloud プランがない場合は、プランが必要だとスイッチが知らせます。プランが終わると、スイッチはオンのまま一時停止になります。

## 新しいデバイスで

1. Fluera をインストールし、同じアカウントでサインインします。
2. ギャラリーにはすぐにキャンバスの一覧が表示されます。まだクラウドにしかないキャンバスには雲のマークが付きます。開いたときにダウンロードされ、それにはネット接続が必要です。
3. 残りは、Wi-Fi か有線ネットワークにつながっていて電池残量が少なくないときに、バックグラウンドで自動的にダウンロードされます。

## 同期されるもの、デバイスに残るもの

スイッチがオンの間、次のものがクラウドに保存されます。

- キャンバス全体：ストローク、セクション、数式、表、グラフ、リンク、リーダーで付けた書き込み入りの PDF、写真
- 録音した講義：音声（分割して）と、音声にひも付いたストローク
- 各キャンバスの学習：回答履歴付きの復習カード、概念、インク付きの試験、ソクラテス式チューター、チャット、想起、概念マップ、コース
- ギャラリーのフォルダー、各キャンバスのフォルダー、ピン留めしたキャンバス、ラベル、ゴミ箱
- Fluera が手書きから認識したテキストと、あなたの修正
- 設定での選択：外観、言語、用紙、復習、試験とリマインダー、色、消しゴムなど

キャンバスの履歴（Time Travel）、取り消し、そのデバイス固有の設定（利き手、手のひら、ペン、ウィンドウ）はデバイスに残ります。ブラウザの折り目には専用のスイッチ **ブラウザの折り目** があり、エンドツーエンドで暗号化されて同期されます。

## 一度に一つの机

あなたのデバイス間では、一つのキャンバスに書き込めるのは一度に一台だけです。

- キャンバスを開いたデバイスが書き込みの番を持ち、1 分ごとに更新します。
- 同じキャンバスがほかのデバイスで開いているときは、ここでは **… で開いています** と表示され、読み取り専用になります。**ここで書く** をタップすると、もう一方のデバイスが保存し、作業をクラウドに送ってから番を渡します。応答がなければ、およそ 1 分半後に番があなたに移ります。
- Fluera をバックグラウンドにすると、デバイスは作業を送って番を手放します。だれも更新しない番は、2 分半たつと自動的に空きます（アプリが閉じている、接続がないなど）。
- 開いている間に別のデバイスでキャンバスが変わったときは **このキャンバスは別の端末で変更されました** と表示されます。**閉じて更新** をタップすると、もう一方の作業がダウンロードされます。

接続がなくても書き込めます。それはデバイス上のあなたのコピーです。

## 競合コピー

同じキャンバスが接続のない 2 台のデバイスで変更された場合、Fluera は一方のバージョンをもう一方で上書きしません。接続が戻ると、片方に欠けている作業は別のキャンバスとしてギャラリーに残ります。

- **「タイトル」・この端末から**：ここで行った作業
- **「タイトル」・もう一方の端末から**：クラウドから届いたバージョン

両方を開いて、必要なものを手でまとめてください。古い Fluera のデバイスは、新しい Fluera で保存されたキャンバスを上書きしません。更新を求め（**クラウドに保存するには Fluera を更新してください**）、その作業は横に並ぶコピー **「タイトル」 — … から、まとめる** としてクラウドに保存されます。

## ゴミ箱とフォルダー

- フォルダーは名前、色、親フォルダー、ピン留めごと同期され、各キャンバスはどのデバイスでも同じフォルダーに入ります。
- **ゴミ箱** に入れたキャンバスは、どのデバイスでもゴミ箱にあります。ゴミ箱の 30 日は、入れた時刻から数え、どこでも同じです。別のデバイスからまた書き込むと、ゴミ箱から出ます。
- フォルダーを削除しても、中のキャンバスは残ります。

## オフにしても何も削除されない

スイッチはどのデバイスからでもオフにでき、すべてのデバイスで止まります。**設定 → プライバシーとテレメトリー** で **Cloud sync** の同意を取り消してもオフになります。オフにしても **何も削除されません**。クラウドにあるものはあなたが削除するまで残り、デバイスにはすべて残ります。

## Cloud プランが終了したら

Cloud プランが終了すると（期限切れ、返金、プラン変更、取り消し）、同期は一時停止し、**6 か月間** はすべてクラウドに残ります。どのデバイスにもダウンロードでき、いつまでかはアプリが知らせます。6 か月を過ぎると、Free プランの 500 MB を超える講義の音声、PDF、写真を、古いものからクラウドから削除することがあります。キャンバスのインクは常に残り、ほかのアカウントと共有しているキャンバスや、非公開カタログのカードからは何も削除しません。その前に Cloud を再開すれば、終了は取り消されます。

## クラウドから削除する

- ゴミ箱のキャンバスで **完全に削除** を選ぶと、それに属するものとともにクラウドから削除されます：ストローク、写真、PDF、講義、回答付きの復習カード、概念、タイトル、学習、認識したテキスト、試験のインク。
- 破棄した試験の回答と、キャンバスから外した写真は、デバイスが接続されしだいクラウドから消えます。
- **クラウド上のデータをすべて削除**（**設定 → プライバシーとテレメトリー**）は、すべてのキャンバス、講義、試験のインク、同期される設定、フォルダーを削除し、すべてのデバイスでスイッチをオフにします。残るのはスイッチの記録（オンとオフにした日時と、ポリシーのバージョン）だけで、これは同意の証拠です。
- **アカウントを削除**（**設定 → プロフィールとアカウント**）は、その記録も削除します。
- **認知メモリ** をオフにすると、そのクラウド上のコピーも削除されます：回答付きの復習カード、概念、概念マップ、ノートのグループのタイトル。

デバイス上のコピーは、そこで削除するまで残ります。

## データの保護

- デバイスでは、ローカルのデータベースが保存時に ChaCha20-Poly1305（sqlite3mc）で暗号化され、鍵はシステムのキーチェーンにあります。
- クラウドでは、データは Supabase の EU リージョン `eu-north-1`（ストックホルム）にあり、通信中（TLS）と保存時はインフラのレベルで暗号化されています。
- 同期はエンドツーエンドで暗号化されて **いません**。Fluera はデータ管理者として、サービスを動かし、守り、サポートするために、技術的にはデータにアクセスできます。データを販売したり、広告に使ったりはしません。例外はブラウザの折り目で、エンドツーエンドで暗号化されています。
