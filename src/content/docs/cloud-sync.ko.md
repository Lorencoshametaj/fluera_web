클라우드 동기화는 노트북마다 선택할 수 있습니다. 한 캔버스는 동기화하면서 다른 캔버스는 완전히 로컬에만 둘 수 있습니다. 직접 동기화를 활성화하기 전에는 데이터가 업로드되지 않습니다.

## 첫 번째 기기에서 동기화 활성화

1. **설정 → 개인정보 보호**를 열고 **클라우드 동기화**를 활성화합니다.
2. 동기화할 노트북을 선택합니다. 노트북을 마우스 오른쪽 버튼으로 클릭하거나 길게 누른 뒤 → **동기화 활성화**를 선택합니다.

동기화된 각 노트북에는 작은 클라우드 아이콘이 표시됩니다. 빨간색은 오류, 회색은 일시 중지를 뜻합니다.

## 두 번째 기기 추가

1. 두 번째 기기에 Fluera를 설치합니다.
2. 같은 계정으로 로그인합니다.
3. 클라우드 동기화가 자동으로 시작됩니다. 중간 크기 노트북의 첫 전체 동기화에는 몇 분이 걸릴 수 있습니다.

## 동기화된 데이터 보호 방식

- 기기에서는 로컬 데이터베이스가 SQLCipher(AES-256)로 저장 시 암호화됩니다.
- 동기화 중 데이터는 TLS로 암호화된 연결을 통해 전송됩니다.
- 서버에서는 EU 인프라(Supabase, `eu-north-1` 리전)에 저장되며 인프라 수준의 저장 시 암호화로 보호됩니다.

분명히 말씀드리면 클라우드 동기화는 **종단 간 암호화가 아닙니다**. 데이터 관리자인 Fluera는 서비스를 제공하고 운영하기 위해 동기화된 콘텐츠에 기술적으로 접근할 수 있습니다. 데이터를 판매하거나 광고에 사용하지 않습니다.

노트북을 암호로 보호된 `.fluera` 파일로 내보내면 해당 파일은 AES-256-GCM으로 별도 암호화됩니다. 내보내기 암호는 그 파일만 보호하며 클라우드 동기화 인증 정보가 아닙니다.

## 데이터 복구

동기화된 노트북은 계정에 연결됩니다. 일반적인 계정 복구 절차를 완료한 뒤 새 기기에서 다시 로그인하면 다운로드할 수 있습니다. 기억하거나 잃어버릴 별도의 클라우드 동기화 패스프레이즈는 없습니다.

## 충돌 해결

한 기기가 오프라인인 동안 두 기기에서 같은 캔버스를 편집하면 Fluera는 벡터 시계가 있는 CRDT를 사용해 변경 사항을 병합합니다. 자동 병합이 모호한 드문 경우에는 해당 노드에 ‘병합 필요’ 표시와 나란히 비교 화면이 나타납니다.

## 특정 노트북의 동기화 비활성화

노트북을 마우스 오른쪽 버튼으로 클릭하거나 길게 누른 뒤 → **동기화 비활성화**를 선택합니다. 클라우드 사본은 즉시 취소되며 로컬 사본은 그대로 유지됩니다.
