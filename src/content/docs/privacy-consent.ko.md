Fluera는 로컬 우선 도구입니다. 기본적으로, 그것을 요구하는 기능을 명시적으로 활성화하지 않으면 기기를 떠나는 것은 없습니다.

## 네 가지 동의 카테고리

**설정 → 개인정보**를 엽니다. 네 개의 토글이 있고, 모두 기본적으로 꺼져 있습니다:

- **제품 분석.** 직접 확인하고 삭제할 수 있도록 계정 식별자에 연결된 사용 데이터 — 기능 사용, 세션 길이, AI 호출 시간. 콘텐츠는 절대 아님. 최대 180일 보관.
- **AI 기능.** Socratic, Ghost Map, LaTeX OCR, Fog of War 사용에 필요. 선택된 캔버스 텍스트는 우리의 서버 측 프록시를 통해 Google Vertex AI가 제공하는 Google Gemini 모델로 전송되며, EU 안에서 처리됩니다(2.5 모델은 europe-west4 네덜란드 / europe-west1 벨기에 리전, 3.x 모델은 Vertex AI의 EU 멀티 리전 엔드포인트). 데이터는 EU 회원국 안에 머뭅니다. 캔버스 전체는 절대 아님.
- **클라우드 동기화.** 기기 간 캔버스 동기화에 필요. 동기화된 데이터는 전송 중(TLS)과 저장 시 EU 인프라(Supabase, `eu-north-1`)에서 암호화됩니다. 종단 간 암호화는 **되지 않습니다**: 데이터 관리자로서 Fluera는 동기화된 콘텐츠에 기술적으로 접근할 수 있습니다. 판매하거나 광고에 쓰는 일은 절대 없습니다. Cloud 요금제에서는 **기기 간 동기화**(아래)가 학습과 설정도 옮깁니다.
- **충돌 보고.** 앱 충돌 시 스택 트레이스와 기기 메타데이터. 사용자 콘텐츠 없음. `sendDefaultPii: false`로 Sentry에 의해 처리됨.

각 토글은 독립적입니다. 분석 없이 클라우드 동기화를 활성화할 수 있습니다. 충돌 보고 없이 AI를 사용할 수 있습니다. 권한은 의도적으로 세분화됩니다.

## 인지 메모리 (온디바이스, 옵트아웃)

위의 네 가지 클라우드 동의와는 별개로, Fluera는 기본적으로 자동 제목, 개념 지도(Ghost Map), 간격 반복(FSRS)을 위해 노트를 **기기에서** 색인합니다. 색인은 기기에서 만들어지고 계산되며 그곳에 남습니다. 단, **기기 간 동기화**(다음 섹션)를 켜면 답변 기록이 담긴 복습 카드, 개념, 개념 지도, 노트 그룹의 제목이 Fluera 클라우드를 거쳐 다른 기기로 갑니다. 메모리는 **설정 → 개인정보 → 인지 메모리**에서 끌 수 있습니다. 색인이 멈추고 이 기기의 인지 데이터는 즉시 지워집니다(노트는 그대로 남습니다). 기기 간 동기화를 사용 중이면 클라우드의 사본도 지워지고, 다시 켤 때까지 다시 올라가지 않습니다. 법적 근거: 반대할 권리가 있는 정당한 이익(GDPR 제6조 1항 f / 제21조) — 그래서 기본으로 켜져 있는 옵트아웃이며, 위의 네 가지 같은 옵트인 동의가 아닙니다.

## 기기 간 동기화 (Cloud 요금제)

**설정 → 데이터와 동기화 → 기기 간 동기화** 스위치는 직접 켜기 전까지 꺼져 있습니다. 계정과 Cloud 요금제가 필요하며 계정 전체에 적용됩니다. 한 기기에서 켜면 로그인하는 모든 기기에서 켜집니다. 켜면 서버가 날짜와 그때 보고 있던 개인정보 처리방침의 버전을 기록합니다. 법적 근거: 계약(GDPR 제6조 1항 b) — 요금을 내는 Cloud 서비스이기 때문입니다.

- **켜져 있는 동안에만 클라우드로 가는 것:** 캔버스 전체(획, 섹션, 수식, 리더에서 표시한 PDF, 사진), 녹음한 강의(나눠진 오디오), 각 캔버스의 학습(답변이 담긴 복습 카드, 개념, 잉크가 있는 시험, 소크라테스식 튜터, 채팅, 회상, 강좌), 갤러리 폴더(이름 포함), 각 캔버스의 폴더, 고정한 캔버스, 라벨, 휴지통, Fluera가 손글씨에서 인식한 텍스트, 설정에서 고른 것(모양, 언어, 용지, 복습, 색, 지우개 등). 한 기기에 묶인 설정(손, 손바닥, 펜, 창)은 그 기기에 남습니다.
- **항상 기기에 남는 것:** 캔버스 기록(Time Travel)과 실행 취소.
- **누가 보나요:** 당신. 공유한 캔버스에서는 멤버가 캔버스와 노트 그룹 제목을 봅니다. 당신의 학습은 당신만 봅니다.
- **어디에:** Supabase, EU 리전 `eu-north-1`(스톡홀름). 전송 중과 저장 시 암호화되지만 종단 간 암호화는 **되지 않습니다**.
- **끄기**는 어느 기기에서 하든 모든 기기에서 멈추고 아무것도 지우지 않습니다. Cloud sync 동의를 철회해도 같습니다.
- **Cloud 요금제가 끝나면** 동기화가 일시 중지되고 6개월 동안 모두 내려받을 수 있습니다. 그 뒤에는 Free 요금제 500 MB를 넘는 강의 오디오, PDF, 사진을 오래된 것부터 지울 수 있습니다. 캔버스의 잉크는 남습니다.
- **삭제:** **휴지통**에서 캔버스를 **완전히 삭제**하면 그 캔버스에 속한 것과 함께 클라우드에서 지워집니다(그 시험의 잉크도 포함됩니다). **설정 → 개인정보 보호와 텔레메트리 → 클라우드에서 내 데이터 모두 삭제**는 모든 캔버스, 강의, 시험 잉크, 설정, 폴더를 지우고 기기 간 동기화를 끕니다. **설정 → 프로필과 계정 → 계정 삭제**는 설정을 포함해 모두 지웁니다.

스위치가 꺼져 있으면 이 모든 것이 예전처럼 기기에 남습니다.

## AI 학습 데이터 (별도, 옵트인 전용)

우리는 Fluera 사용자가 실제로 쓰는 방식에 맞춘 자체 손글씨 인식기를 만들고 있습니다. **설정 → 개인정보 → AI 학습 데이터**에는 스위치가 두 개 더 있으며, 역시 기본적으로 꺼져 있고 위의 네 개와는 독립적입니다:

- **보정 세션 (약 5분).** 한 번만 하는 안내 세션으로, 화면에 나오는 기호 30개(숫자, 수학 연산자, 그리스 문자, 자주 쓰는 문자)를 씁니다. 화면의 기호가 정답이 되어 당신의 획과 짝을 이룹니다.
- **쓰는 동안 자동 수집.** 캔버스에 평소처럼 쓰는 동안 원시 획(좌표, 시간, 필압, 지원되는 경우 펜 기울기)과 각 클러스터의 작은 암호화 PNG를 저장합니다. 데이터는 우리 서버에서 암호화된 상태로 남습니다. **Google과의 계약이 마무리되면**(Vertex AI 데이터 처리 계약, 진행 중) Google Gemini가 이미지를 분석해, 당신이 쓴 것을 Fluera에 가르칠 수 있게 합니다. 그때까지 학습 데이터는 우리 인프라에서 제3자에게 나가지 않습니다.

두 스위치는 당신의 기기에서 계산되는 전용 가명 식별자를 쓰며, 제품 분석의 식별자와 **다릅니다**: 데이터만으로는 기여를 당신의 계정과 연결할 수 없습니다.

이 카테고리의 특별 보호 조치:
- 업로드 *전에* AES-256-GCM으로 데이터 암호화. 복호화 키는 비대칭 키 쌍(X25519)이며, 개인 키 절반은 오프라인 종이에 보관되고 디지털화되지 않습니다.
- Supabase 테이블의 Row-Level Security: 다른 사용자의 샘플은 읽을 수 없습니다.
- 노이즈 필터: 총 3점 미만의 클러스터(탭, 번짐)는 저장 전에 버립니다.
- 기하학적 지문을 통한 영구 중복 제거: 같은 클러스터를 똑같이 다시 그려도 중복이 생기지 않습니다.
- **설정 → AI 학습 데이터 → 최근 수집**에서 샘플별 미리보기: 우리가 저장한 것 그대로의 썸네일을 볼 수 있습니다.

## 결코 수집되지 않는 것

- 캔버스의 콘텐츠 (sqlite3mc, ChaCha20-Poly1305로 정지 시 암호화). 단, **기기 간 동기화**(위)를 켠 경우는 예외입니다
- AI가 묻는 질문, 또는 당신의 답
- 녹음한 오디오. 단, **기기 간 동기화**(위)를 켜면 캔버스처럼 클라우드로 갑니다(전송 중과 저장 시 암호화, 종단 간 아님)
- 명시적 동의 없는 어떤 종류의 개인 식별 정보

## 검증 방법

네 개의 스위치를 끄고 방화벽이나 네트워크 모니터를 지켜보세요: 캔버스, 녹음, 쓴 내용은 기기에 남습니다. 그래도 앱은 캔버스 내용이 담기지 않은 일로 네트워크와 통신합니다. 예를 들어 계정 로그인, 스토어를 통한 구독 확인(RevenueCat), 일부 기능에 필요한 모델 다운로드, 카탈로그의 카드를 설치하거나 학습할 때의 마켓플레이스 신호(기본값은 켜짐, **설정 → 개인정보 보호와 텔레메트리 → 마켓플레이스 신호**에서 끔), 내장 브라우저에서 여는 페이지입니다.

## 동의 철회

네 개의 토글은 모두 항상 **설정 → 개인정보**에서 액세스 가능합니다. 토글을 끄는 것은 즉시 적용됩니다. 이미 수집된 데이터가 어떻게 되는지는 카테고리마다 다릅니다.

- **제품 분석:** 철회가 우리 서버에 도착하면 계정으로 이미 수집된 텔레메트리가 즉시 삭제됩니다. 어떤 경우에도 180일을 넘겨 보관되지 않습니다.
- **AI 기능:** 요청은 즉시 멈추며, 우리 서버에서도 멈춥니다. AI 사용 기록(어떤 기능인지, 토큰 수, 내용 없음)은 플랜 한도를 위해 24개월 동안 보관됩니다.
- **클라우드 동기화:** 이를 끄거나 기기 간 동기화를 꺼도 이미 클라우드에 있는 것은 지워지지 않습니다. 지우려면 **클라우드에서 내 데이터 모두 삭제**를 사용하세요.
- **충돌 보고:** 철회해도 이미 보낸 보고서는 지워지지 않습니다. Sentry는 이를 30일 동안, 암호화된 백업은 최대 90일 동안 보관합니다.

계정과 클라우드의 데이터를 삭제하려면 **설정 → 프로필과 계정 → 계정 삭제**를 사용하세요. 안 되면 계정 주소로 [lorenco@fluera.dev](mailto:lorenco@fluera.dev)에 이메일을 보내세요.
